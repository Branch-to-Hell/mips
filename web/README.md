# Website

Report website for the project, built with [Astro Starlight](https://starlight.astro.build) and deployed on Vercel (Root Directory: `web`).

```powershell
cd web
npm install
npm run dev      # http://localhost:4321
npm run build    # output in dist/
```

Pages live in `src/content/docs/` (one Markdown file per page). The sidebar is set in `astro.config.mjs`.
