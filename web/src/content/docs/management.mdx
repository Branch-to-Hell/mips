## How we worked

- **GitHub Project board:** Backlog → To do → In progress → In review → Needs lab → Done. At most 2 cards in progress per person.
- **One branch per task**, from an up-to-date `main`; `main` only changes through pull requests. Every PR has evidence (ModelSim, MARS or a board photo), and one person reviews and merges.
- **Contracts first:** addresses, the memory map, the pipeline rules and the MMIO registers were agreed in `docs/contracts.md` before writing the modules that depend on them.
- **Simulation before the lab:** nothing went to the board without passing simulation first, and every lab visit had a checklist.

## Declaration of AI use

The spec asks to declare, **per module**, the tool, the purpose, what we kept or discarded and how we checked it. Our rule (`docs/workflow.md`): AI is used wherever it saves time, the test is asked for together with the module, and **nothing generated is done until a test proves it works**. Every member must be able to explain their module without notes.
